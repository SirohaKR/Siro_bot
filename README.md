# 시로냥 — 메이플스토리 길드 관리 봇

역할 지정(직업/직급)과 채널 관리를 담당하는 디스코드 봇입니다.
파이썬을 잘 몰라도 따라할 수 있도록 설치부터 실행까지 순서대로 정리했습니다.

**설정은 명령어가 아니라 브라우저로 여는 "설정 페이지"에서 합니다.** 페이지에서
채널·역할을 고르고 버튼을 누르면, 봇이 알아서 공지 채널에 메시지를 올리거나
음성채널을 만듭니다. 실제로 항상 켜져 있어야 하는 프로그램은 두 개입니다.

- `main.py` — 디스코드에 접속해서 이모지 반응/음성채널 입장을 실시간으로 감시하는 "본체"
- `web/app.py` — 브라우저로 여는 설정 페이지 (설정할 때만 잠깐 켜도 되고, 계속 켜둬도 됨)

## 1. 폴더 구조

```
discordBot_시로냥/
├── main.py                ← 봇 본체 실행 파일. "python main.py"
├── requirements.txt        ← 필요한 파이썬 라이브러리 목록
├── .env.example            ← 토큰 등 비밀값을 넣는 양식 (복사해서 .env로 만들어 사용)
├── cogs/                   ← 기능별로 나눠놓은 폴더 ("Cog" = 기능 서랍 하나)
│   ├── roles.py            ← 공지 메시지의 이모지 반응을 감시해서 역할을 부여/회수
│   └── channels.py         ← 파티모집 허브 채널 입장을 감시해서 개인 음성채널 자동 생성/삭제
├── core/
│   ├── settings_store.py  ← 서버별 설정(어떤 역할/채널을 쓰는지)을 data/settings.json에 저장
│   └── discord_api.py     ← 설정 페이지가 디스코드에 직접 요청을 보낼 때 쓰는 코드
├── web/
│   ├── app.py              ← 설정 페이지 실행 파일. "python web/app.py"
│   └── templates/          ← 설정 페이지의 화면(HTML)
└── data/                   ← 처음 실행하면 자동으로 생기는 폴더. settings.json 저장됨
```

기능을 하나 더 추가하고 싶어지면, `cogs/` 안에 파일을 하나 더 만들고
`main.py`의 `INITIAL_EXTENSIONS` 목록에 이름만 추가하면 됩니다.

## 2. 준비물

- Python 3.10 이상 ([python.org](https://www.python.org/downloads/)에서 설치, 설치 시 "Add python.exe to PATH" 체크)
- 디스코드 계정 + 봇을 초대할 서버(길드 서버)의 관리자 권한

## 3. 디스코드 봇 만들고 토큰 발급받기

1. [Discord Developer Portal](https://discord.com/developers/applications) 접속 → 로그인
2. **New Application** 클릭 → 이름은 아무거나 (예: 시로냥) → Create
3. 왼쪽 메뉴 **Bot** 클릭 → **Reset Token**(또는 처음이면 바로 토큰 발급) → 나오는 토큰을 복사
   - 이 토큰은 비밀번호와 같습니다. 절대 남에게 보여주거나 깃허브에 올리지 마세요.
4. 같은 Bot 페이지에서 **Privileged Gateway Intents** 항목을 찾아 아래 두 개를 켜세요(ON).
   - **SERVER MEMBERS INTENT** — 역할을 부여/제거하려면 필요
   - (선택) MESSAGE CONTENT INTENT는 이 봇은 쓰지 않으므로 꺼둬도 됩니다.

## 4. 봇을 서버에 초대하기

1. 왼쪽 메뉴 **OAuth2 → URL Generator**로 이동
2. **SCOPES**에서 `bot` 체크 (슬래시 명령어를 안 쓰므로 `applications.commands`는 필요 없음)
3. **BOT PERMISSIONS**에서 아래 권한 체크
   - Manage Roles (역할 관리) — 이모지 반응으로 직업/직급 역할 부여
   - Manage Channels (채널 관리) — 파티모집 개인 채널 생성/삭제
   - Move Members (음성채널 이동) — 허브 채널 입장 시 개인 채널로 이동
   - Manage Messages (메시지 관리) — 한 사람이 이모지 여러 개를 눌렀을 때 나머지를 정리
   - View Channels, Send Messages, Embed Links, Add Reactions
4. 맨 아래 생성된 URL을 복사해서 브라우저 주소창에 붙여넣고, 봇을 넣을 서버를 선택해 초대

⚠️ **중요**: 초대 후 서버 설정 → 역할(Roles) 메뉴에서, 봇의 역할을 봇이 부여해야 하는
역할들(직업 역할, 직급 역할)보다 **위쪽**으로 옮겨주세요. 디스코드는 자기보다 낮은 순서의
역할만 부여/제거할 수 있어서, 순서가 안 맞으면 "역할 부여 실패" 오류가 납니다.

## 5. 설치 및 실행

프로젝트 폴더(`discordBot_시로냥`)에서 터미널(명령 프롬프트/PowerShell)을 열고:

```bash
pip install -r requirements.txt
```

`.env.example` 파일을 복사해서 이름을 `.env`로 바꾸고, 안에 있는 값들을 채웁니다.
- `DISCORD_TOKEN` → 3단계에서 복사한 토큰
- `WEB_ADMIN_TOKEN` → 설정 페이지 접속용 비밀번호 역할. 아무 문자열이나 길게 지어서 입력
- `FLASK_SECRET_KEY` → 아무 문자열이나 (세션 암호화용)

그다음 **터미널 두 개**를 열어서 각각 실행합니다 (하나는 봇 본체, 하나는 설정 페이지).

```bash
python main.py
```

```bash
python web/app.py
```

`main.py` 콘솔에 `✅ 시로냥 봇 실행/연결 완료`가 뜨면 봇 본체는 성공.
`web/app.py` 콘솔에는 실행 중인 주소가 표시됩니다. 종료할 때는 각 터미널에서 `Ctrl + C`.

## 6. 설정 페이지 사용법

먼저 서버에서 사용할 역할(전사/마법사/... , 길드마스터/부길드장/...)과 음성채널을
디스코드에서 미리 만들어두세요. 설정 페이지는 "이미 있는 역할·채널을 연결"하는 방식으로
동작합니다 (음성채널은 페이지에서 바로 새로 만들 수도 있습니다).

1. 브라우저에서 `http://localhost:5000/?token=여기에_WEB_ADMIN_TOKEN값` 접속
   (봇을 PC가 아니라 서버에 올렸다면 `localhost` 대신 그 서버 주소를 사용)
2. 서버가 여러 개면 목록에서 설정할 서버를 선택
3. 화면에서 아래 순서로 설정
   - **1. 직업 선택 공지 만들기** — 공지 채널과 직업별 역할·이모티콘을 고르고 "공지 게시하기".
     → 그 채널에 메시지가 올라가고, 길드원이 이모티콘을 누르면 역할이 자동으로 부여됩니다.
   - **2. 파티모집 음성채널 설정** — 기존 음성채널을 고르거나 새 이름을 입력해서 "허브 채널 설정".
     → 그 채널에 들어가면 개인 파티 채널이 자동 생성되고, 비면 자동 삭제됩니다.
   - **3. 길드 직급 역할 연결** — 길드마스터/부길드장/길드원/신입길드원에 서버 역할을 연결.
   - **4. 멤버에게 직급 부여** — 멤버와 직급을 골라서 관리자가 직접 부여 (셀프 지급 아님).

값을 바꾸고 싶으면 언제든 같은 페이지에서 다시 설정하면 됩니다 (덮어쓰기 방식).

## 7. 자주 겪는 문제

- **설정 페이지에 "접근 권한이 없습니다"가 떠요** → 주소 끝에 `?token=...`이 정확히
  `.env`의 `WEB_ADMIN_TOKEN`과 같은지 확인하세요.
- **역할/멤버 목록이 비어 보여요** → 3단계의 SERVER MEMBERS INTENT를 켰는지 확인하고,
  `.env`의 `DISCORD_TOKEN`이 올바른지 확인하세요.
- **"역할 부여 실패" 계열 오류가 나요** → 4단계의 ⚠️ 안내처럼 봇의 역할 순서를 부여하려는
  역할보다 위로 올려주세요. 디스코드는 자기보다 낮은 순서의 역할만 부여/제거할 수 있습니다.
- **이모티콘을 눌러도 역할이 안 붙어요** → `main.py`(봇 본체)가 켜져 있는지 확인하세요.
  설정 페이지(`web/app.py`)는 공지를 "올리는" 역할만 하고, 실제 반응 감지는 `main.py`가 합니다.
- **봇이 오프라인으로 보여요** → `python main.py`를 실행한 터미널 창을 닫으면 봇도 꺼집니다.
  계속 켜두려면 터미널을 그대로 두거나, PC를 껐다 켜도 계속 돌게 하려면 별도의 서버(VPS)나
  Docker 배포가 필요합니다 (필요하면 요청해주세요, 추가로 구성해드릴 수 있습니다).
